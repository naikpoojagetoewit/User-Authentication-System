# User Authentication System

## Overview
User Authentication System is a Java-based web application developed to demonstrate secure user registration and login functionality. The application allows users to create accounts, store credentials in a MySQL database, and authenticate themselves through a login interface.

## Features
- User Registration
- User Login Authentication
- Database Connectivity using JDBC
- Form Validation
- Session Management
- Secure Data Storage in MySQL

## Technologies Used
- Java
- JSP (Java Server Pages)
- Servlets
- JDBC
- MySQL
- HTML
- CSS

## Project Structure
- Registration Module
- Login Module
- Database Connectivity Module
- Authentication Module

## Installation

### Clone Repository
bash
git clone <repository-url>


### Configure Database
1. Create a MySQL database.
2. Create the required user table.
3. Update database credentials in the project.

### Run the Application
1. Deploy the project on Apache Tomcat Server.
2. Start the server.
3. Open the application in your browser.

## Workflow
1. User registers with valid details.
2. Information is stored in the MySQL database.
3. User logs in using registered credentials.
4. System validates the credentials and grants access.
